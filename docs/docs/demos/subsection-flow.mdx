# Subsection Flow

A flow that lives **inline inside a page** — no modal, no overlay. Useful for multi-step forms, inline confirmations, or collapsible wizards embedded in a larger UI.

Click **Begin Checkout** below to start the flow directly on this page.

```jsx live
function CheckoutSection() {
  // Keyframes live in a runtime <style> tag: keyframes defined in the site's
  // CSS but referenced only from JS inline styles get stripped/renamed by the
  // production CSS minifier.
  const fadeStyles = `
@keyframes demo-checkout-fade-out {
  from { opacity: 1; }
  to   { opacity: 0; }
}
@keyframes demo-checkout-fade-in {
  from { opacity: 0; }
  to   { opacity: 1; }
}
`;

  const { init, status: flowStatus, result, SequentOutlet } = useSequentFlow();
  const message =
    flowStatus === "idle" && result?.status === "resolved"
      ? `Order placed! ${JSON.stringify(result.value)}`
      : null;

  function StepAddress() {
    const { advance, context } = useSequentStep();
    const [address, setAddress] = React.useState(context?.address ?? "");
    return (
      <div>
        <strong>Step 1 — Shipping Address</strong>
        <p>Enter your address details here.</p>
        <div>
          <input
            type="text"
            value={address}
            onChange={(e) => setAddress(e.target.value)}
            placeholder="123 Main St, City, State"
          />
        </div>
        <button onClick={() => advance(() => StepPayment, { address })}>Next →</button>
      </div>
    );
  }

  function StepPayment() {
    const { retreat, advance, context } = useSequentStep();
    const [card, setCard] = React.useState(context?.card ?? "");
    return (
      <div>
        <strong>Step 2 — Payment</strong>
        <p>Enter your payment details here.</p>
        <div>
          <input
            type="text"
            value={card}
            onChange={(e) => setCard(e.target.value)}
            placeholder="Card number (e.g., 4111 1111 1111 1111)"
          />
        </div>
        <div>
          <button onClick={() => retreat()}>← Back</button>
          <button onClick={() => advance(() => StepReview, { card })}>Next →</button>
        </div>
      </div>
    );
  }

  function StepReview() {
    const { retreat, resolve } = useSequentStep();
    const { context: ctx } = useSequentContext();
    return (
      <div>
        <strong>Step 3 — Review & Confirm</strong>
        <p>Everything looks good?</p>
        <div>
          <button onClick={() => retreat()}>← Back</button>
          <button onClick={() => resolve({ ...ctx, confirmed: true })}>Place Order ✓</button>
        </div>
      </div>
    );
  }

  function IdleContent() {
    const { context: ctx } = useSequentContext();
    return (
      <div>
        <button onClick={start}>{ctx ? "Begin Checkout Again" : "Begin Checkout"}</button>
      </div>
    );
  }

  function start() {
    init(() => StepAddress);
  }

  return (
    <div className="demo-checkout">
      <div>
        <strong>Checkout</strong>
      </div>
      <SequentOutlet
        transition={({ previousStep, nextStep, phase, onExited, transitionKey }) => {
          if (phase === "exited") return nextStep;
          return (
            <div style={{ position: "relative" }}>
              <style>{fadeStyles}</style>
              <div
                key={`exit-${transitionKey}`}
                style={{ position: "absolute", animation: "demo-checkout-fade-out 300ms forwards" }}
                onAnimationEnd={onExited}
              >
                {previousStep}
              </div>
              <div key={`enter-${transitionKey}`} style={{ animation: "demo-checkout-fade-in 300ms" }}>
                {nextStep}
              </div>
            </div>
          );
        }}
      >
        <IdleContent />
      </SequentOutlet>
      {message && <div>{message}</div>}
    </div>
  );
}
```

## How it works

1. The `IdleContent` component is passed as children of `<SequentOutlet />` — it renders as idle content until a flow is active.
2. `IdleContent` calls `useSequentContext()` to check if a previous flow completed — if so, the button reads "Begin Checkout Again".
3. Clicking the button calls `init(() => StepAddress)`, which replaces the idle children with `StepAddress` inside the outlet.
4. Each step calls `advance(NextStep)` to move forward or `retreat()` to go back.
5. `StepReview` calls `resolve(value)` — `useSequentFlow().result` captures the resolved value, the outlet returns to idle, and the `IdleContent` reappears with the updated button label.
6. The outlet's `transition` render prop crossfades between steps — the outgoing step animates out while the incoming step animates in.

## Key points

- **Idle children** — the outlet renders its children when no flow is active. Idle children have access to `useSequentContext`, which returns the last consumer context from the previous flow (or `undefined` on first render).
- **No central state** — each step decides what comes next via `advance(NextStep)`.
- **History is automatic** — `retreat()` pops the history stack with no manual bookkeeping.
- **Animated transitions** — the `transition` render prop mounts both steps during a step change and drives the crossfade via CSS keyframes, wired to `onAnimationEnd` for the exit completion signal.
- **The outlet is reusable** — the same `useSequentFlow()` host can start a fresh flow with another `init()` call.
